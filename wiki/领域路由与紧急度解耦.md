# 领域路由与紧急度解耦

专业领域决定主辅 Agent；CRITICAL 不再强制替换为 EscalationAgent。
明确 ESCALATION / HUMAN_HANDOFF 意图仍走升级角色。

单 Agent、并行协作、低置信度澄清路径统一返回 urgency 和 escalation_reason。
升级原因：explicit_handoff（明确要求升级）、critical_urgency（最高紧急度）、agent_requested（Agent 请求升级）。无升级需求时为 null。
escalated=true 表示需要升级处理，不表示已经通知或接通人工。
API 回执与工具 trace 保留这些字段；角色上下文继续携带紧急度。

当前没有人工派单服务或优先级调度队列，本次不承诺实际提速、人工接入或 SLA。
后续可由调用方消费升级原因接入人工流程；该接入需要另行实现可靠投递及状态跟踪。
